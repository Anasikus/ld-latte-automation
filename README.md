# LD LATTE — Automation Test Assignment

Тестовое задание по автоматизации бизнес-процессов: **n8n, React, TypeScript и Supabase**.

## Демонстрация

[Открыть веб-приложение](https://anasikus.github.io/ld-latte-automation/)

## Реализованные части

**1. Telegram-бот — n8n + Supabase.** Динамические inline-кнопки для активных услуг, обработка /start и callback, проверка актуальности услуг. [Workflow JSON](n8n/telegram-services.json).

**2. Веб-приложение — React + Supabase.** Авторизация, создание и редактирование заявок, поиск, фильтрация, адаптивный интерфейс и RLS.

**3. Instagram Analytics — технический план.** Сбор статистики нескольких профессиональных аккаунтов (подписчики, охват, просмотры и публикации), архитектура, метрики, план внедрения и тест-план. Реальная интеграция не реализована.

## Технологии

React · TypeScript · Vite · SCSS · Supabase · PostgreSQL · n8n · Telegram Bot API · Meta Instagram API
