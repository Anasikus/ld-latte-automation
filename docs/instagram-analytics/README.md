# Задание 2 — план сбора аналитики Instagram для LD LATTE

**Статус:** проектное решение, не действующая интеграция. Дата подготовки: 31.10.2026.

## Цель
Автоматически собирать показатели нескольких профессиональных Instagram-аккаунтов (подписчики, охват, просмотры, статистика публикаций), сохранять историю и предоставлять данные для отчётности.

## Предлагаемый стек
Meta Instagram API → n8n → Supabase (PostgreSQL) → отчётность. Для авторизации — официальный OAuth Meta; без запроса паролей пользователей. Токены и секреты — только на серверной стороне.

## Важные границы
1. Это **Instagram Analytics**, не Instagram Direct и не обработка заявок.
2. Нужны профессиональные аккаунты и подходящий набор разрешений Meta. Тип входа (Instagram Login или Facebook Login) выбирается после проверки фактических аккаунтов и требований приложения.
3. Названия метрик, допустимые `period`, разрешения и доступность endpoint зависят от версии API, типа аккаунта/медиа и статуса приложения. **Перед реализацией сверить с актуальной документацией Meta и проверить пробными запросами.**
4. Исторические значения и охват не всегда доступны за произвольные периоды; недоступные значения записываем как `NULL` с причиной, а не как ноль.
5. В составе задания не заявляем, что реальные аккаунты подключены или статистика уже собирается.

## Демонстрация решения
На защите показать схему, последовательность подключения 2–3 аккаунтов, пример формата сохраняемых записей, матрицу метрик и сценарии с истёкшим токеном, недоступной метрикой и повторной загрузкой без дубликатов.
