# План тестирования Instagram Analytics

**Статус:** проект тестирования, реальная интеграция не развёрнута.

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| IG-01 | Подключение профессионального аккаунта | Успешная авторизация OAuth, подключение сохранено |
| IG-02 | Подключение нескольких аккаунтов | Данные каждого аккаунта разделены по connection_id |
| IG-03 | Запрос числа подписчиков | Сохранён актуальный снимок followers_count |
| IG-04 | Получение insights | Сохранены доступные метрики с периодами и временем сбора |
| IG-05 | Сбор публикаций с пагинацией | Список не обрезается на первой странице |
| IG-06 | Повторная синхронизация | Upsert не создаёт дубликатов |
| IG-07 | Истёкший или отозванный токен | Статус reconnect_required, запись ошибки, запрос переподключения |
| IG-08 | Ошибка 429 или 5xx | Ограниченные повторы с backoff и логирование |
| IG-09 | Метрика недоступна | NULL и unavailable_reason, не подмена нулём |
| IG-10 | Отсутствие прав доступа к чужому аккаунту | Данные другого владельца недоступны |
| IG-11 | Разные часовые пояса | Корректная привязка к периодам и UTC |
| IG-12 | Сравнение с Instagram Insights | Расхождения документируются с учётом задержек API |

## Критерии готовности

Проверены выбранный OAuth flow и разрешения, реальные ответы API для согласованных метрик, разделение данных аккаунтов, повторные запуски без дубликатов, обработка отказов и корректность отчётов. До подключения тестовых аккаунтов все сценарии остаются **NOT RUN**.
