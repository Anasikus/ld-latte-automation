# Архитектура LD LATTE

Telegram-бот предоставляет актуальный список услуг и позволяет пользователю выбрать интересующую услугу с помощью inline-кнопок.

### Реализованные возможности

- Автоматическая обработка команды `/start`.
- Получение активных услуг из Supabase REST API.
- Динамическое формирование inline-клавиатуры.
- Обработка событий `callback_query`.
- Проверка актуальности выбранной услуги.
- Отображение уведомления с названием услуги.
- Обработка отсутствия активных услуг.
- Обновление списка без изменения кода workflow.

### Архитектура

```text
Telegram Trigger
       |
     Switch
       |
       +-- /start
       |      |
       |   Supabase REST API
       |      |
       |   Code: формирование кнопок
       |      |
       |   Telegram sendMessage
       |
       +-- callback_query
              |
           Supabase REST API
              |
           Code: проверка услуги
              |
           Telegram answerCallbackQuery
```

Данные загружаются из Supabase при каждом вызове `/start`. При выборе услуги бот дополнительно проверяет, остаётся ли она активной.

### Тестирование

| Сценарий | Результат |
|---|---|
| 0 активных услуг | Сообщение об отсутствии услуг |
| 2 активные услуги | Две inline-кнопки |
| 5 активных услуг | Пять inline-кнопок |
| 9 активных услуг | Девять inline-кнопок |
| Выбор активной услуги | Уведомление с названием услуги |

Все перечисленные сценарии проверены вручную.

### Экспорт workflow

Файл: [`n8n/telegram-services.json`](../n8n/telegram-services.json)

Экспорт содержит узлы, условия маршрутизации, JavaScript-код и связи между узлами.

Токены и параметры подключений заменены заполнителями. Для запуска необходимо указать собственные значения.
### Ответ на выбор услуги

После нажатия inline-кнопки бот подтверждает callback через `answerCallbackQuery` и дополнительно отправляет название выбранной услуги в чат через `sendMessage`. Для недоступной услуги пользователь получает предложение обновить список.
