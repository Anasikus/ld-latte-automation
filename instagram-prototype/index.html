ПРОВЕРКИ И НАДЁЖНОСТЬ

Что заложено в модель

  • Изоляция статистики разных аккаунтов по ID подключения
  • Повторная синхронизация без дублирования снимков (upsert)
  • Истёкший токен → статус переподключения, без бесконечных повторов
  • 429 / 5xx → ограниченные повторы, журнал ошибок
  • Отсутствующая метрика → NULL и причина, а не 0
